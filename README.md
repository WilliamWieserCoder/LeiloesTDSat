# 🏷️ LeiloesTDSat

## 📋 Descrição do Projeto
Sistema informatizado para gerenciamento de casas de leilões, desenvolvido para automatizar e otimizar as rotinas diárias, incluindo cadastro de itens, gestão de participantes e controle de lances.

## 🛠️ Tecnologias Utilizadas
- **Java** - Linguagem de programação principal
- **MySQL** - Sistema de gerenciamento de banco de dados
- **NetBeans IDE** - Ambiente de desenvolvimento integrado
- **Git/GitHub** - Controle de versão
- **Apache Ant** - Ferramenta de automação de build

## 🚀 Funcionalidades Principais
- Cadastro de itens para leilão
- Registro de participantes
- Gerenciamento de lances
- Controle de datas e horários
- Relatórios de vendas

## 📦 Estrutura do Projeto
LeiloesTDSat/

├── src/ # Código fonte
├── nbproject/ # Configurações do NetBeans
├── build.xml # Script de build Ant
├── manifest.mf # Arquivo de manifesto
└── README.md # Documentação

## 🗄️ Banco de Dados
O projeto utiliza MySQL. Execute o script SQL para criar as tabelas necessárias.
